# Data Set propio – Ethan Zambrana

Actividad: Familiarización del entorno y creación de un conjunto de datos propio.

## Archivos
- `Ethan-Zambrana.ipynb`: notebook con carga, exploración, análisis y visualizaciones.
- `dataset_ventas.csv`: conjunto de datos sintético de 200 ventas.

## Cómo ejecutar
1. Abre `Ethan-Zambrana.ipynb` en Jupyter Notebook, JupyterLab o Google Colab.
2. Asegúrate de que `dataset_ventas.csv` esté en la misma carpeta.
3. Ejecuta las celdas en orden.

## Dependencias
```bash
pip install pandas numpy matplotlib
```

**Nota:** los datos son simulados con fines académicos y no corresponden a ventas reales.
